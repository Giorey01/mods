03 / ApproachThe same for every mod
A

Source in the open

Every mod is a public repository under the MIT licence, with a build script and notes on how it works. No game files, no decompiled code.

B

One line to install

An installer for Windows and one for Linux and Steam Deck. It finds the game, adds the mod loader if it is missing, and checks every download.

C

Honest about its state

Each page says what was tested and what was not. Mods stay out of your saves and achievements, and out of other players' way.
